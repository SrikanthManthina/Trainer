# Trainer

A training management application.

## Overview

Trainer is a platform for managing training programs, courses, and learner progress.

## Features

- Create and manage training courses
- Track learner progress
- Generate reports and analytics
- User management

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
git clone https://github.com/srikanthmanthina/trainer.git
cd trainer
npm install
```

### Running the App

```bash
npm start
```
